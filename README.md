# benchmark-tracker

A person or an agent keeps benchmark sets in this app. A workbook is an export. Excel only reads it.

Python 3 standard library. No build step, no pip install. The working model goes in `SPEC.md`.

## Run

```bash
python3 run.py                 # opens http://localhost:8766/
```

On Windows: `C:\msys64\usr\bin\bash.exe -lc "cd ~/work-journal/2026/nocopy/benchmark-tracker && python3 run.py"`.
